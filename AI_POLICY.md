# AI Contribution Policy

AI-assisted development is permitted.

Examples:
- GitHub Copilot
- Claude Code
- Codex
- Cursor
- Continue.dev
- Local LLMs

## Contributor Responsibilities

All submitted code must be reviewed by a human before submission.

The contributor is fully responsible for:
- Correctness
- Testing
- Performance
- Compatibility
- Licensing compliance

AI-generated output must not be submitted without review.

## Pull Requests

Please disclose significant AI assistance in the PR description.

Example:

AI Assistance:
- GitHub Copilot for initial implementation
- Claude Code for refactoring
- Human reviewed and tested

## Not Allowed

- Submitting code you do not understand
- Submitting untested AI-generated code
- Uploading proprietary or confidential material to AI services
- Generating content that violates RimWorld or mod licensing terms

## Maintainer Rights

Maintainer may reject AI-generated contributions that:
- Lack understanding
- Lack testing
- Create unnecessary complexity
- Appear to be low-quality automated output
